# The Mysterious Island
A 2D Unity action-platformer. Survive a cursed island, dodge traps, solve puzzles, and fight Seraphites and bosses with sword, bow, and gun.

## Story
You wash up on a cursed island after the war. Yuto, a survivor who has been stranded for years, helps you through traps and hidden rooms. Hostile Seraphites and castle dwellers stand between you and escape — and the island has worse waiting at the end.
## Features
- Side-scrolling platforming with wall climb, crouch, shield, and zip-lines
- Melee, bow, and gun combat (ammo is limited)
- Traps, falling platforms, chests, and keypad puzzles
- NPC dialogue and a story that runs across multiple levels
- Checkpoints, lives, and save/load
- Pause menu and in-game How to Play
## Controls
| Action | Key |
| --- | --- |
| Move | A / D |
| Jump / climb | Space |
| Crouch | S |
| Shield | Hold C |
| Sword / bow / gun | 1 / 2 / 3 |
| Attack / shoot | Left click |
| Talk to Yuto | Q |
| Open chests, keypads, zip-lines, elevators | E |
| Zoom out | Hold Z |
| Pause | Esc |
## Getting started
**Requirements:** [Unity Hub](https://unity.com/download) and **Unity 2021.3.10f1** (same version the project was built with).
1. Clone this repository.
2. In Unity Hub, choose **Open** and select the project folder.
3. Open `Assets/Scenes/Start Scene.unity` and press Play.
